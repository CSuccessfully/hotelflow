# HotelFlow: definición del problema (Fase 1)

## Quién tiene el problema

El recepcionista de un hotel. Es la persona que atiende a los huéspedes en el mostrador y que, en el día a día, tiene que saber qué habitaciones están libres, para qué fechas y a nombre de quién está cada reservación. Trabaja con presión de tiempo: el huésped está frente a él y espera una respuesta inmediata.

## Qué hace hoy para resolverlo

Lleva las reservaciones de forma manual o con herramientas que no fueron hechas para esto: una libreta, una hoja de cálculo o mensajes de WhatsApp. Para saber si hay un cuarto disponible en ciertas fechas, revisa esas notas una por una.

## Qué le cuesta o le impide hacerlo

Revisar a mano toma tiempo y se presta a errores. Puede asignar dos veces la misma habitación en las mismas fechas, perder o duplicar datos de un huésped, o no encontrar rápido una reservación para modificarla o cancelarla. Además, no tiene una vista clara de las reservaciones activas.

## Qué evidencia hay de que el problema existe

Este proyecto es un caso simulado para fines académicos, por lo que no se realizó una investigación de campo con un hotel real. El problema se plantea a partir de una situación conocida en la gestión hotelera: cuando las reservaciones se llevan de forma manual (libreta, hoja de cálculo o mensajes), es fácil asignar dos veces la misma habitación en fechas que se cruzan o perder datos de un huésped. Estos supuestos quedarían por validar con un recepcionista real antes de construir una versión completa. Para este MVP, el problema se toma como hipótesis de trabajo.

## Qué pasa si no se resuelve

El hotel pierde ingresos por habitaciones mal asignadas o vacías por error, los huéspedes se molestan al llegar y encontrar su cuarto ocupado, y el recepcionista pierde tiempo y se estresa en cada consulta.

## Frase del problema

Los recepcionistas de hoteles necesitan una forma rápida y confiable de consultar disponibilidad y gestionar reservaciones, porque hacerlo a mano provoca errores como dobles reservaciones.
