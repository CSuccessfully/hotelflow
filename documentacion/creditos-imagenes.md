# Créditos de imágenes

Las fotografías de hoteles son recursos de demostración previstos para el catálogo ficticio de HotelFlow. Si una fotografía no está disponible localmente, la interfaz utiliza `frontend/img/sin-imagen.svg`, una ilustración propia creada para este proyecto.

No se usan enlaces externos ni fotografías de hoteles reales presentadas como establecimientos de HotelFlow.

## Recursos propios de demostración

Las cinco imágenes `hotel-casa-norte-1.webp`, `hotel-casa-norte-2.webp`,
`hotel-patio-del-sol-1.webp`, `hotel-patio-del-sol-2.webp` y
`hotel-jardin-serrano-1.webp` son ilustraciones originales generadas
programáticamente por el equipo para este proyecto. No representan hoteles
reales, no contienen personas identificables y se distribuyen bajo licencia
propia del proyecto HotelFlow (uso libre dentro de este repositorio).

`logo-hotelflow.svg` es un logotipo vectorial original creado para HotelFlow,
bajo la misma licencia propia del proyecto.

La carpeta `frontend/vendor/leaflet/` contiene Leaflet distribuido localmente bajo su licencia BSD-2-Clause. Los mosaicos de OpenStreetMap se usan solo como capa cartográfica y la interfaz conserva un estado de respaldo si no están disponibles.
